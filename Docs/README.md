# Docs

Project documentation is grouped by role.

## Folders

- `system/`: current architecture, baseline system snapshots, and implementation state.
- `evaluation/`: evaluation dataset schema, retrieval debug docs, benchmark metrics, and experiment reports.
- `logs/`: day-by-day development logs.
- `process/`: workflow rules and team/process notes.
- `reviews/`: project reviews and external/internal review notes.
